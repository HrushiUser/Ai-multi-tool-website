💡 AI-Powered Solutions Hub

A fully frontend-based AI tools website with 6 smart features — built using only **HTML, CSS, and JavaScript**, with **localStorage** for data handling.

🚀 Features
1. **AI Chatbot Interface** – Real-time chatbot using text input.  
2. **AI Content Generator** – Create blogs, descriptions, and articles from prompts.  
3. **AI Text Summarizer** – Summarize long text into key points instantly.  
4. **AI Image Generator** – Generate 1–4 images using creative prompts.  
5. **Smart Notes Panel** – Save ideas and responses in persistent local notes.  
6. **AI Translator** – Translate text into different languages instantly.

🛠️ Tech Stack
- HTML, CSS, JavaScript (Vanilla)
- localStorage for login, signup, and notes

✅ Benefits
- No backend or hosting needed  
- Lightweight and fast  
- Great for learning and AI prototyping
